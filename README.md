# River Raid for the ZX Spectrum Next

A port of River Raid (Activision, Atari 8-bit, 1983) to the ZX Spectrum Next, based on the
C++ port in [djdron/river_raid](https://github.com/djdron/river_raid). Work in progress:
the first step is a river viewer.

No part of the original game is included: the program reads your own cartridge image
(`River_Raid.rom`, 8192 bytes) at run time.
