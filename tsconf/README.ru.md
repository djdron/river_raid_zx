# River Raid для TS-Conf

Порт на TS-Conf (ZX Evolution / Pentevo): отдельный проект со своей сборкой, отдельно от
версии для ZX Spectrum Next (корень репозитория). Общая только `../deps` (sjasmplus, порт на
C++, Xpeccy+: `make deps` в корне).

Пока: вьювер. Attract mode работает так же, как в игре на Next (та же логика игры, display и
генератор реки, скопированы в `src/`), а показывается по-TS-Conf'овски:

- река в режиме 256 цветов, 320x240, строка картинки — 512 байт (320 точек в начале), 512
  строк по кольцу, прокрутка аппаратная (GYOFFS): новая строка реки пишется сразу в свою
  строку картинки (`render.asm`), без копирований;
- цвет берега меняется по строкам, как это делает Copper на Next: кадровое прерывание
  переставляется вниз по кадру от смены к смене (`build_events`, `irq`), каждое пишет CRAM
  через FM-окно строкой раньше;
- выше и ниже реки — чёрный тайловый слой 0;
- спрайтов, панели и звука пока нет. Только 50 Гц (PAL): кадр платы.

На 14 МГц работа кадра занимает в среднем ~63 000 тактов, максимум ~91 000, из ~287 000.

Память (окна по 16K): $0000 — память Atari (страница 1), $4000 — пробеги строк и буферы
(страница 5; `render_line` на время рисования ставит туда страницу картинки), $8000 —
программа и картридж с $A000 (страница 2), $C000 — программа, буферы и стек (страница 6);
картинка с 32-й страницы, карта тайлов в странице 7, точки тайла в странице 8.

    make          build/river_raid.spg: программа для Wild Commander (SPG 1.0); River_Raid.rom
                  она сама находит на SD-карте (ниже)
    make sna      build/river_raid.sna: снапшот 128K с твоим ROM внутри (../rom/River_Raid.rom)
    make check    гоняет тестовую сборку на ядре TSConf из Xpeccy+ и сравнивает её с портом
                  на C++ кадр за кадром (FRAMES=... сколько, по умолчанию 3000), потом картинку
                  последнего кадра по точкам
    make palette  заново пишет src/palette_ts.inc (цвета порта на C++ в уровнях платы)

.spg собирается и на GitHub (workflow `tsconf`: его артефакт). Положи River_Raid.rom (образ
картриджа, 8192 байта) куда угодно на SD-карту: программа при старте ищет его на карте
(`load_rom.asm`: первый раздел или вся карта, FAT16 или FAT32, сначала корень, потом папки,
до 8 уровней; длинное имя в любом регистре или короткое RIVER_~1.ROM). Без него — красный
бордюр.

`build/tools/tscheck -spg build/river_raid.spg 600 out.ppm -sd папка` гоняет .spg с папкой
хоста вместо SD-карты (`-img файл`: образ карты); `-sna build/river_raid.sna 600 out.ppm` —
снапшот.
